# Shop (E-commerce Module)

Модуль Shop предоставляет функциональность полноценного интернет-магазина на базе ELF CMS.

## 🚀 Возможности

- Управление товарами и категориями
- Атрибуты товаров, варианты (SKU), изображения и описание
- Корзина и оформление заказа
- Способы доставки и оплаты
- Управление заказами и покупателями
- Интеграция с другими модулями (например, пользователи, уведомления, формы)

## 📦 Установка

Модуль не является открытым и доступен только по коммерческой лицензии.

Вы можете получить его:
- Бесплатно при заказе разработки интернет-магазина у ELF Digital
- Или приобрести отдельно, обратившись по email: info@elfweb.de

## ⚙️ Использование

После установки модуль будет доступен в административной панели ELF CMS. Для работы необходимы модули: Users, Roles, Forms, E-Mail Events.

## 🧩 Требования

- Laravel >= 10.0
- PHP >= 8.1
- ELF CMS >= 3.0.11
