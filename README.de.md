# Shop (E-commerce Module)

Das Shop-Modul bietet vollständige E-Commerce-Funktionalität für ELF CMS.

## 🚀 Funktionen

- Verwaltung von Produkten und Kategorien
- Produktattribute, Varianten (SKU), Bilder und Beschreibungen
- Warenkorb und Checkout-Prozess
- Versand- und Zahlungsmethoden
- Bestell- und Kundenverwaltung
- Integration mit anderen Modulen (z. B. Benutzer, Benachrichtigungen, Formulare)

## 📦 Installation

Dieses Modul ist proprietär und nicht frei verfügbar.

Sie können es erhalten:
- Kostenlos bei der Beauftragung eines Online-Shops bei ELF Digital
- Oder durch separaten Lizenzerwerb via info@elfweb.de

## ⚙️ Verwendung

Nach der Installation erscheint das Modul im ELF CMS Adminbereich.  
Benötigt Kernmodule wie Users, Roles, Forms und E-Mail Events.

## 🧩 Anforderungen

- Laravel >= 10.0  
- PHP >= 8.1  
- ELF CMS >= 3.0.11
